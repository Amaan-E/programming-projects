Assignment 1: Electricity Bill Calculator Using Packages and Interfaces
Problem Statement:
A power distribution company wants to automate the process of calculating electricity bills for
different categories of consumers. The billing rules are different for Domestic and Commercial
consumers. Develop a Java application using packages and interfaces to calculate the monthly
electricity bill.
Create an interface BillCalculator containing a method calculateBill(). Implement this interface in
two classes: DomesticConsumer and CommercialConsumer.
Store the interface and implementation classes in a package named electricity, and create a separate
package mainapp containing the driver program.
The billing criteria are as follows:
Consumer Type Rate per Unit
Domestic ₹6 per unit
Commercial ₹9 per unit

The program should:
Accept consumer name, consumer ID, and units consumed.
Calculate the electricity bill based on the consumer type.
Display complete bill details.
Demonstrate the use of interfaces, packages, and runtime polymorphism.

Problem Statement:

Create an interface SalaryCalculator with a method calculateSalary().
Implement the interface in:
PermanentEmployee
ContractEmployee
Create separate packages for employee classes and the main application.
The program should:
Accept employee details.
Calculate gross salary for permanent employees:
Gross Salary = Basic Pay + HRA (20%) + DA (10%)
Calculate salary for contract employees:
Salary = Hours Worked × Hourly Rate
Display complete salary details.
